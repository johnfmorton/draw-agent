## [Unreleased]

### Added

- `snow-cursive-study-1` artwork (part one of a multi-part study): a single snowflake centered on the canvas. One arm is grown from the center as a stem with mirrored branch pairs (Branch Levels, Branches per Level, Branch Angle, Branch Scale, Branch Start, Branch Taper, and seeded Jitter that is keyed per pair so each arm stays a mirror of itself), then replicated around the center point (Arms). The Lettering group switches the skeleton between plain lines and Secondhand Cursive renders of words from a `WORDS` list laid along every segment: Word Length sets how many words fit per segment and how big they are, Word Variants (up to 40, default 24) sets how many distinct handwritten renders are scattered across the segments, cycling through the word list, and a separate Lettering Seed owns that pool — one API call per variant, reused everywhere it appears — so re-rolling the main Seed changes the geometry and word placement without new API calls, and Pen Width previews strokes at the real pen width
- `snow-cursive-study-2` artwork (part two): the same snowflake sized for a 6 × 4 in postcard, with the defaults tuned for the smaller canvas — a shorter arm so the outer branches clear the border, and longer words so the lettering stays plottable
- `grid-play-01sep2026` artwork: a 6 × 4 in starter piece with its controls organized into Basics and Borders groups
- Collapsible control groups: controls can declare an optional `group` name (e.g. `group: 'Grid Controls'`) and render together in a collapsible section of the panel, placed where the group's first member appears in the schema. Collapse state persists per artwork in localStorage; a collapsed group whose values differ from file defaults shows a dirty dot, and the header shows a member count. The control editor dialog gains a Group field (with autocomplete of existing group names), the field round-trips through Export and write-to-file, and drag-reordering can move a control into, out of, or between groups — dropping anywhere on a group section adds the control to it (the header being the way into a collapsed one). Groups themselves are draggable too: a grip in the group header moves the whole section (members included) among top-level controls and other groups, and the file order follows. A 📁 button in the control panel header creates a new empty group with a "drag controls here" drop zone; empty folders are session-only (with an × to remove) until their first control lands, and a group whose last control is dragged out stays as an empty folder instead of vanishing

- Border mask for pen plotter safety: `src/border-mask.ts` exports `applyBorderMask(svg, canvasConfig, { inset, drawBorder })`, which clips artwork to a rectangle inset from the canvas edge so the pen never runs off the paper. Because plotter drivers ignore SVG `clip-path` and plot raw geometry, the mask rewrites coordinates directly (Liang–Barsky clipping of `<line>`, `<polyline>`, `<polygon>`, and `<rect>` strokes, splitting chains that exit and re-enter into multiple polylines; `<path>` data — curves included — circles, ellipses, rounded rects, and shapes inside transformed groups are normalized to an exact line/bezier model (`src/path-geometry.ts`), clipped by splitting curves precisely at the border, and rewritten in place with local units and inherited styles intact; filled shapes are boolean-intersected with the mask so their outline hugs the border). `drawBorder: true` also plots the border rectangle as a frame. Calibration marks are exempt. `noise-field-study` demos it with a Border Mask mode dropdown (Off / Mask only / Mask + border) and a Border Inset slider. The controls are now standard equipment: artworks generated by the wizard or `npm run new` include the dropdown, the slider, and the `applyBorderMask` call by default (right after the calibration toggle), and every existing artwork in `art/` has been retrofitted with the same controls and call (defaults: Mask + border, 24 px inset)
- Automatic pen plotter calibration marks: `src/calibration.ts` draws red crosshairs inset 8px from the four canvas corners, derived from the canvas's physical size in any unit; new artworks generated by the wizard or CLI include the call and a "Show calibration marks" toggle by default, and all existing artworks in `art/` have been updated with the same toggle and call. The toggle is always the first control in the panel, and mark strokes use `vector-effect: non-scaling-stroke` so they stay crisp when large canvases are scaled down in the preview (plotters follow the geometry, so plotted output is unchanged)
- 4×6 in and 6×4 in canvas presets (postcard/photo size) in the preset dropdown and New Artwork wizard
- Secondhand Cursive lettering helper (`src/secondhand-cursive.ts`): typesets text via the Secondhand Cursive API and composes the stroke geometry into an artwork's SVG — `cursiveInCircle` (fill a circle with a margin), `cursiveAt` (place at a point, true physical size or scaled), plus `fetchCursive`/`withCursive`/`cursiveGroup` for custom layouts. Responses are cached per request so repeat renders are synchronous and stay off the API throttle; `penWidthMm` previews strokes at the real pen's line width. The API token is read from `VITE_SECONDHAND_CURSIVE_TOKEN` in `.env.local` (gitignored). Requests rejected by the API's 60/min rate limit are retried after a shared 10 s pause (up to 8 times) instead of leaving their lettering out of the render
- Exports are now guaranteed clipped: exporting re-applies the border mask geometrically to a clone of the preview (`reapplyBorderMask`, driven by the mask bounds stamped on the svg root), so geometry that arrived after the initial draw — Secondhand Cursive lettering on a cache miss — is cut at the border too, and the rare element that cannot be rewritten (unparseable path data, degenerate transform) is removed rather than plotted unclipped. An exported SVG needs no downstream processing (no vpype crop): what the file contains is what the plotter draws
- Secondhand Cursive lettering can be rotated: `cursiveInCircle`, `cursiveAt`, and `cursiveGroup` accept `rotateDeg` (degrees clockwise about the ink box's center — the circle center for `cursiveInCircle`, whose diagonal-based fit keeps any rotation inside the circle). The rotation is a standard SVG transform, so the border mask and export clipping rewrite it exactly. `post-card-6x4-version-2` gains a Text Rotation slider (−180° to 180°)
- The control panel is now resizable: a draggable gutter on its left edge (matching the editor pane's) sets the panel width, clamped between 320px and 70% of the window, and the chosen width persists in localStorage
- Vitest test suite (`npm test`): the path parser/normalizer, arc→cubic conversion, transform math, exact curve clipping (tangency, corner crossings, idempotence — what makes the export-time re-clip safe), boolean filled-shape clipping, and jsdom integration tests for the border mask, late-arriving lettering, and both export branches

### Changed

- A clipped closed shape no longer lifts the pen at its (arbitrary) start point when both sides of the seam survive clipping: the last surviving run is merged into the first
- Switching the canvas unit dropdown now converts the width/height values so the physical size is preserved (6×4 in becomes 152.4×101.6 mm instead of 6×4 mm); the width/height inputs are wider so converted values display without clipping
- `gu-grids` control labels now name the mode they affect (e.g. "Noise: Scale", "Quadtree/Voronoi: Points") with tooltip descriptions, making it clear why a control has no visible effect in the current grid mode
- Annotation labels in the study artworks enlarged (8–14px → 14–20px) so they're readable at the preview's display scale
- `curve-math-study` length label now converts px to the canvas's physical unit and reports total pen travel for everything drawn (curve, offsets, ticks, and split highlight)

### Fixed

- Control panel rows no longer clip their contents: long labels ("Show calibration marks") wrap instead of truncating with an ellipsis, vector X/Y inputs keep a usable width with the magnitude readout on its own line below (previously all three fought over one line and the inputs collapsed to slivers), and slider rows no longer push their ↩ reset button past the panel edge (the range input's intrinsic width couldn't shrink)
- Optimized SVG export wrote its `viewBox` in canvas units (e.g. `0 0 8.5 11`) against path data in 96-DPI pixels, so the drawing landed at 1/96 scale in a corner of the page; the viewBox is now in pixels and matches the physical width/height attributes
- Optimized SVG export left curve commands (`C S Q T A`) untransformed when flattening groups, exporting transformed curves — Secondhand Cursive lettering among them — at the wrong position and size; transforms are now baked into every command exactly (arcs become cubics on the way), and stroke widths are scaled to match flattened scale transforms
- Optimized SVG export recursed into `<defs>`, plotting clip-path rectangles as ink; non-drawable containers (defs, clipPath, mask, symbol, metadata, title, desc) are now skipped
- Stroke-reversal optimization silently mis-tracked the pen position for curve paths (`reversePathData` returned them unchanged while the start/end metadata swapped); curve paths now reverse correctly via the normalized model
- Border mask visual clip no longer clips the wrong region of transformed shapes: the fallback clip-path used canvas coordinates but was attached to elements *inside* transformed groups, where userSpaceOnUse units are re-read in the group's local space — Secondhand Cursive lettering (a translate+scale group of paths) lost everything left of / above the inset expressed in its own millimeter coordinates. The clip now lands on each affected top-level node, wrapped in an untransformed <g> when the node carries a transform, so it always cuts at the real border. (First render of uncached lettering is now clipped the moment it lands, via the mask's MutationObserver, and exports re-apply the mask regardless — see the export guarantee entry.)
- Preview no longer distorts or hides tall canvases: the svg was clamped by independent CSS max-width/max-height rules, which broke its aspect ratio (letterboxing the drawing inside a wider white box) and let flex centering push the top of the page — calibration marks included — behind the header, unreachable by scroll. The preview is now sized in JS to fit the pane at the canvas's true aspect ratio (refit on resize via ResizeObserver) with overflow-safe centering
- URL hash values are now validated on load: unknown dropdown options, non-numeric numbers, malformed points/rectangles, and bad canvas sizes or units are dropped (falling back to working values or file defaults) instead of flowing into app state, localStorage, and re-encoded URLs
- `post-card-6x4-version-2` calibration marks: transposed line coordinates produced zero-length lines; each corner point now draws a red crosshair, and Bottom Right defaults to the canvas's actual bottom-right corner. The marks now come from the shared calibration helper, so the hardcoded Top Left / Bottom Right point controls (576×384 = 6×4 in at 96 DPI) are gone and the marks follow the canvas size automatically

### Security

- Updated `vite` (6.4.3), `postcss` (8.5.26), and `nanoid` (3.3.18) to patched releases, clearing all npm audit / Dependabot advisories (vite `server.fs.deny` bypass and launch-editor NTLMv2 hash disclosure on Windows; PostCSS sourceMappingURL file disclosure and XSS; nanoid infinite-loop cases)

## [1.2.0] - 2026-07-15

### Added

- "New Artwork" wizard dialog in the header (dev server only): filename/title, paper-size presets, SVG.js or raw DOM, and optional helper starter examples — creates a ready-to-run artwork file that draws a seeded starter shape
- Shared artwork file template (`src/artwork-template.ts`) used by both the wizard and `npm run new`, eliminating template drift
- Optional helpers prompt in the `npm run new` CLI matching the wizard's choices
- Create-safe artwork endpoint: `POST /__art/<name>?create=1` returns 409 instead of overwriting an existing file
- New helper dependencies for plotter work: `simplex-noise` (seedable flow-field noise), `polygon-clipping` (boolean polygon ops for occlusion/hatching), `bezier-js` (curve splitting, measuring, offsets) with local type declarations for bezier-js
- Example study artworks for the package helpers: `noise-field-study` (simplex-noise flow field with field-tick view), `polygon-clipping-study` (hidden-line removal via union/difference/intersection, plus hatching clipped to visible regions), and `curve-math-study` (bezier-js curve lab: offsets, normals, splitting, bbox, length)

- "Write to art/&lt;name&gt;.ts" option in the control dialog (on by default, dev server only): adding, editing, or deleting a control rewrites the `controls` block in the artwork file and saves it, so UI-created controls persist without the copy/paste round-trip
- Writing controls to the artwork file also keeps the `const { ... } = values;` line in `draw()` in sync — newly added control values are immediately usable in code, and renamed/deleted controls don't leave stale bindings behind
- Drag-and-drop control reordering via a grip handle on each row; the new order persists to the artwork file (honors the same write-to-file preference)

### Fixed

- Generated artwork template no longer references `values.seed` (a type error) when no seed control exists
- Exported controls code now escapes apostrophes in labels/descriptions correctly (previously produced invalid TypeScript)

## [1.1.0] - 2026-07-13

### Added

- In-browser code editor (CodeMirror 6) that edits artwork files directly on disk — save with Cmd+S, collapsible and resizable pane, and conflict detection when a file changes externally (e.g. in VS Code)
- Console panel below the preview capturing `console.log`/`warn`/`error`, uncaught errors, and unhandled promise rejections, with duplicate-message collapsing and error/warning count badges
- Prettier formatting on save, plus a Format button (Shift+Alt+F) in the editor
- Vite dev-server endpoint (`/__art/*`) for reading and writing artwork source files
- Prettier configuration (`.prettierrc.json`) matching the project's single-quote style
- Favicon for browser tab

### Fixed

- HMR updates no longer stack duplicate event listeners or insert a duplicate canvas-controls container when `main.ts` re-executes
